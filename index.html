Что это

Совместный журнал клиентов и мероприятий. Записи хранятся в Google Sheets, файлы — в Google Drive.

Права по ролям

  • Администратор — полный доступ.
  • KAM (ЭТМ / РС) — видит записи своего дистрибьютора, редактирует только свои, ставит задачи только РП.
  • РП — видит только свои записи, редактирует только свои, ставит задачи только себе.

Валидация ИНН

ИНН проверяется автоматически: 10 цифр для юрлиц, 12 для ИП/физлиц, плюс контрольная сумма по алгоритму ФНС. Если ИНН неверный — запись не сохранится.

SDS CRM FSK

1. Установка и вход

  • Сайты: sds-crm-fsk.netlify.app или sds-crm-fsk.github.io/sds-crm-fsk.
  • Компьютер: откройте сайт в Chrome/Edge → иконка установки в адресной строке.
  • Android: Chrome → ⋮ → «Установить приложение».
  • iPhone: Safari → «Поделиться» → «На экран "Домой"».
  • Регистрация: вкладка «Регистрация» → Имя, Фамилия, email, пароль, код из письма. Затем ждите подтверждения администратора.

2. Роли и права

РольВидитРедактируетЗадачиАдминка
АдминистраторВсёВсе записиВсем✅
KAM ЭТМТолько ЭТМТолько своиРП по ЭТМ❌
KAM РСТолько РСТолько своиРП по РС❌
РПТолько своиТолько своиТолько себе❌

3. CRM-журнал

  • ИНН: обязательно. Валидация формата + контрольная сумма. 10 цифр — юрлицо, 12 — ИП.
  • Дубли: по ИНН + Дистрибьютор запрещены. Для нового этапа — «📜 История».
  • Дедлайны: кликните на «⚠️ Просрочено» или «📅 На этой неделе» в баннере — таблица отфильтруется.
  • Дашборд: карточка «📊 Дашборд» на главном экране — ABC, дистрибьюторы, регионы, статусы.

4. Задачи

  • KAM: ставит задачи РП своего дистрибьютора (статус «на согласовании»).
  • РП: ставит задачи только самому себе.
  • Админ: любому пользователю, сразу открытая.
  • Подтверждение: задачи от KAM и РП подтверждает администратор.
  • Результат: исполнитель может вписать текст результата через кнопку «📝 Результат».
  • Переназначение автора: только админ может сменить автора задачи через кнопку «🔄 Автор».
